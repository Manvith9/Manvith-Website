## *Real-Time Chat Platform*
### Networking · Distributed Backend Systems

### • React.js, Node.js, WebSockets
### • Redis, PostgreSQL, JWT

I built a real-time messaging platform supporting more than 1,000 concurrent WebSocket connections.

I implemented JWT-based authentication and Redis Pub/Sub for distributed message delivery, reducing message-delivery latency by approximately 50% in my testing. I also designed backend APIs, PostgreSQL schemas, session management, and user and conversation workflows.

This project gave me hands-on experience with persistent connections, asynchronous communication, distributed messaging, authentication, and low-latency backend systems.
