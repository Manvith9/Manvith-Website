## *VoteSecure — Secure Online Voting Backend*
### Backend Engineering · Authentication

### • Node.js, Express.js
### • MongoDB, JWT, REST APIs

I developed the backend for an online voting application using Node.js and Express.js, with an emphasis on authenticated access, structured data management, and reliable API design.

I implemented JWT-based authentication and Aadhaar-style identity-verification logic for access control and designed MongoDB schemas for voter and candidate management.

I deployed the application online with attention to data security and reliability. The project strengthened my experience with authentication, authorization, backend architecture, and data modeling.
